1 · Slotting DOM into a canvas

HTML-in-canvas wants the drawn DOM to be a descendant of the <canvas>. A shadow root lets the canvas live in the shadow tree while your content stays in the light DOM: each named <slot> inside the canvas pulls in the matching child, and that child is drawn with drawElementImage(). The text below is real DOM: select it, tab to the input, type, click.

Light-DOM content

This card is a child of <canvas-slot>, not of the canvas. A <slot name="note"> inside the shadow canvas reprojects it.
“The slot is display: contents, so the slotted element becomes the canvas's layout child.” 
<script type="module" src="/lib/canvas-slot.js"></script>

<canvas-slot id="hero">
  <article slot="note">…</article>
  <form slot="form">…</form>
</canvas-slot>

<script type="module">
  const hero = document.getElementById('hero');   // the <canvas-slot> element

  // Called on every paint. ctx is the canvas's 2D context;
  // draw(slotName, x, y) is drawElementImage() for the element in that slot.
  hero.onrender = ({ ctx, draw, time }) => {
    ctx.rotate(Math.sin(time / 900) * 0.04);
    draw('note', 20, 20);
    draw('form', 60, 170);
  };
</script>

Re-slotting: move content in and out of the canvas

Changing an element's slot attribute reassigns it. Nothing is cloned or moved in the DOM, the canvas just gets a slotchange and repaints.

Takeaways

  • Slotted light-DOM elements can be drawn directly. drawElementImage(lightChild) works when the light child is assigned to a slot inside the canvas, because layout and paint use the flat tree.
  • The <slot> itself can't be the drawable. It is display: contents, so it has no box and no paint record ("No cached paint record for element"). Put drawable on the slotted element, or on a real wrapper element in the shadow tree around the slot.
  • A shadow wrapper works too. <div drawable><slot></slot></div> inside the canvas draws everything slotted into it as one image, which is handy when you don't want to touch the author's markup.
  • The limit is the host's children. A slot can only reproject children of its shadow host. It does not let you pull an arbitrary element from elsewhere in the page into the canvas; for that, see the OffscreenCanvas and cross-tab demos.
  • Hit testing, focus and selection follow the drawn position, because drawElementImage updates the element's geometry automatically.
