Reading the same page

When two people read one document, each of them can see what the other has selected. A shared editor does this by sending the start and end of the selection, not the pixels, and each reader's own copy of the page draws the mark.

A browser keeps one selection per document, and in Chrome it holds one range. So another reader's selection cannot be a second real selection. It has to be drawn some other way: wrapped in elements, registered as a custom highlight, or painted by a canvas that knows where the text is.

Here the canvas draws them. Each reader has a colour, a bar at the end of the selection that is still moving, and a flag with a name. Your own selection is drawn the same way and stays a real selection that can be copied.
