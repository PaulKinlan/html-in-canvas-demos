What happens when the DOM can go anywhere a pixel can?

The HTML-in-canvas API lets a canvas draw real elements. They can be bent by a shader, hung in a 3D scene, torn off into another window or sent to a phone, and they are still elements: you can click them, type in them, select them and read them with a screen reader. This site is a place to learn the API and to see what it makes possible. Every page runs live in your browser and says what works and what doesn't.

The building block

canvas-slot.js is one dependency-free module. Children with a slot name are projected into a canvas; you get a render callback with a draw(name, x, y) helper. Add worker="…" to render off the main thread, or pair it with slot-share.js to publish slots to other tabs and origins. 

<script type="module" src="https://html-in-canvas-demos.kinlan-test.workers.dev/lib/canvas-slot.js"></script>

<canvas-slot id="stage">
  <h2 slot="title">Real DOM</h2>
  <button slot="cta">Still clickable</button>
</canvas-slot>

<script type="module">
  const stage = document.getElementById('stage');   // the <canvas-slot> element

  // draw(slotName, x, y) is drawElementImage() for the element in that slot.
  stage.onrender = ({ ctx, draw, time }) => {
    ctx.rotate(Math.sin(time / 800) * 0.05);
    draw('title', 20, 20);
    draw('cta', 20, 90);
  };
</script>

What the platform still needs

Building these turned up the same few gaps again and again. They are written up with the evidence in FINDINGS.md.

  • Draw an element by reference. Today the element must be inside the canvas, which is why so much here leans on slots and shadow roots.
  • More than one hit box per element. An element drawn in two places, or in pieces, answers in only one. Every portal, lens and shard works round that.
  • A snapshot that draws into a second canvas. An ElementImage is bound to its source canvas, so crossing a document means sending pixels and sending input back.
  • Undrawn should mean inert. An element in the canvas that is not drawn can still take focus. It is the one sharp edge in an otherwise good accessibility story.
