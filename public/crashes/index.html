Every way a page of this project has crashed the tab or lost its canvases while using HTML-in-canvas, one entry each. An entry says what was done, what happened, in which browser, whether a script measured it or it was reported from a phone, where to reproduce it, what is not known, and what the pages do now. "Copy as a report" gives one entry as plain text, with the number of matching reports that real devices have sent.

How it works

  • The entries are written by hand in /crashes/cases.js from the findings of each page. Each says "measured" (a script or a page produced it, in the browser named) or "reported" (seen on the project owner's phone, with what came back).
  • /shared/context-guard.js runs on every page. It sends each lost context, each stopped loop of losses, script errors and a tab that died to /api/reports. The browser sends its own crash reports there through the Reporting API. /canvas-loss/ sends the outcome of each trial.
  • An entry names the report types that count towards it, with text the report must contain. The page asks the log for each and shows the total.
  • No reproduction runs here. A link opens the page that does, and several of those crash the tab.

Findings

State on 2026-11-21. Headless Chromium 157 for "measured", Chrome 159 on Android for "reported".

  • Five renderer crashes reproduce in Chromium 157 and involve a drawable canvas: a view transition on a drawable child, an iframe changed inside paint, adoptNode() of a painted canvas, opacity around a canvas in a drawn iframe, and loseContext() on a drawable WebGL canvas. Two have a page that isolates them.
  • Two context losses on Chrome 159 for Android have their call identified: a drawable 2D canvas made with willReadFrequently, and a float16 getImageData(). Neither happens in the test browser. The first was isolated by /canvas-loss/ on the phone; the second has not run alone yet.
  • None has been filed. The entries that have no isolating page need one before filing.
  • Not verified: that Chrome on Android sends crash reports for a dead tab to this site. None had arrived when this was written.
