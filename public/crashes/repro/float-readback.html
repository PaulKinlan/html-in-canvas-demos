getImageData() with pixelFormat "rgba-float16" loses float16 2D contexts

A 2D canvas with colorType: "float16" and colorSpace: "display-p3". Button A fills it and reads one pixel as float. Button B is a drawable canvas that draws an element first, as the page that showed the loss does. A second float16 canvas is on the page and is never read.

Expected: the pixel values, and no contextlost event.
Seen: Chrome 159 on Android, on /hdr-glow/ (case B, with more on the page): every float16 2D context on the page lost within moments of each float readback. Not yet run alone on that phone. Headless Chromium 157: no loss.
