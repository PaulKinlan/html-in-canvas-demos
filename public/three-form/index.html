How is this hit tested?

On every pointer move the scene is raycast. The triangle and UV under the pointer give a small affine map that is exact at that spot, and updateElementGeometry() puts the element there.

How it is put together

import * as THREE from 'three';
import { HTMLSurfaces } from '/lib/html3d.js';

const renderer = new THREE.WebGLRenderer({ canvas });   // <canvas content="drawable">
const surfaces = new HTMLSurfaces(renderer, camera, { scene });

surfaces.add(form,  laptopScreen);                 // flat: one projective matrix
surfaces.add(guest, curvedWall, { hit: 'mesh' });  // curved: geometry follows the pointer

renderer.setAnimationLoop(() => { surfaces.update(); renderer.render(scene, camera); });

Takeaways

  • The method names moved. three.js r187 ships HTMLTexture, but it calls gl.texElementImage2D and queue.copyElementImageToTexture. Chromium 157 has texElementSubImage2D and drawElementImageToTexture, so stock three draws nothing until a small shim is installed. html3d.js feature-detects both spellings.
  • Hit testing needs updateElementGeometry(). three's InteractionManager positions elements with a CSS matrix3d. In this build a CSS transform on a WebGL-drawn element does not make it hit-testable; a perspective DOMMatrix passed to updateElementGeometry() does, and bounding rects, focus rings and the caret follow it.
  • Curved surfaces work if the geometry follows the pointer. A rectangle cannot be mapped onto a cylinder with one matrix, but a mouse hit test only looks at one point. Raycast, take the triangle's UV Jacobian, and re-place the element on every pointer move.
  • Occlusion is yours to handle. The DOM has no idea a drone is in front of the screen. The same raycast parks a hidden surface's geometry off-canvas so clicks cannot pass through scene objects.
  • Touch is the weak spot for curved surfaces. A tap has no pointer move before it, so the hit test runs against the flat fallback placement. Flat surfaces are exact for touch.
  • Mipmaps matter. Uploading into our own immutable sRGB texture and calling generateMipmap() keeps the billboard readable from across the scene. three's stock path uses a single level.
