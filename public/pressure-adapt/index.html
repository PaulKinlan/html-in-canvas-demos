How it works

The card starts as ordinary HTML in #card-host, then upgrades to the fair 2D route on load so the page doesn't open a WebGL context before it's needed. When PressureObserver reports a CPU state (or when you pick a tier in the selector), the stage hands the same <article> element between backends using moveBefore().

TierBackendFrame budgetWhat changes
nominal WebGL 2 via ElementGL 60 fps while on screen Uploads the card with texElementSubImage2D() only when it changes, draws chromatic glass refraction and ripple distortion, and keeps hit boxes aligned with updateElementGeometry().
fair 2D canvas via drawElementImage() 30 fps throttled Disposes the WebGL stage, moves the card into a 2D canvas and retires the WebGL canvas with window.__gfx?.retire(). Draws a light tilt and drifting highlight with a 5-argument drawElementImage() call.
serious 2D canvas on-demand 0 idle frames Stops the requestAnimationFrame loop completely. The canvas paints only when Chromium fires a paint event (for example when you type, drag the slider or press a toggle).
critical Plain HTML 0 frames, 0 canvases Calls moveBefore() to lift the live card straight back into #card-host, removes drawable and retires the canvas so canvas memory drops to 0.0 MB while your text and controls stay intact.

Pressing "Burn CPU briefly (1.5 s)" spawns up to four short-lived Web Workers (falling back to chunked main-thread work if workers are blocked) for 1.5 seconds so you can push real CPU load without locking the page. Any continuous animation pauses automatically when the stage leaves the viewport or the tab is hidden, and stops animating when prefers-reduced-motion: reduce is set.

Live checks

These four checks run on isolated fixtures in the corner of the window, never on the card above. Because two of them create a WebGL context and wait for canvas retirement, they wait for a tap.

Findings

  • Starting the page on the 2D fair tier avoids opening a WebGL context at load, while letting a live nominal sensor reading or a tap upgrade the same card to ElementGL.
  • Using moveBefore() to move the card between a WebGL canvas, a 2D canvas and the plain #card-host container keeps strict DOM node identity (===), typed text, slider position and toggle state across all four tiers.
  • Calling window.__gfx?.retire(oldCanvas) after removing a canvas hands its WebGL context or 2D buffer back to the site guard instead of waiting for garbage collection, so stepping to critical drops the card's canvas memory to 0.0 MB.
  • On the serious tier, stopping requestAnimationFrame and avoiding timer-driven DOM edits inside the card keeps idle paints at zero; Chromium fires paint only when you interact with a control.
  • In Chromium, PressureObserver.observe('cpu') may report nominal straight away on desktop hardware, or reject in restricted frames and headless containers. Having manual tier overrides and a short CPU burst button lets you verify every tier on any device.
  • Real thermal throttling and phone GPU memory recovery on Android Chrome are not verified in a headless browser. Open this page on a phone and run the live checks to measure them on real hardware.
